## 架构质量：高

### starLayout.ts — 整批代码中设计最精到的模块

实现了两个独立语义轴：

- **径向距离 = 时间**：古代哲人靠近中心，当代在外围。有精确的年代线性插值，无年代时通过 period bucket 回退。
- **Y 轴 = 思想性格**：形而上/超验传统偏上（platonism: 0.9），政治/实践传统偏下（confucianism: −0.65），以 `traditionYScore` 映射表实现。

colorKey 使用 `civilization:tradition` 复合键，允许儒家/道家在同一文明内显色不同。这些设计决策高度一致，是对应用核心隐喻（星图）的深度实现。

### ThoughtSystem — 最重要的计划外扩展

引入三层思想系统（Problem → Claim → Evidence），同时体现在：

- `schemas.ts` 的 Zod schema（含 weight、themeIds）
- `PhilosopherPanel.tsx` 的可展开 UI
- `StarScene.tsx` 的 `ThoughtOrbit`——选中哲人后，思想命题以小球绕星公转，主张再向外扩展一层

方向判断正确。原始计划的扁平 Argument 结构更接近数据库，ThoughtOrbit 才真正体现"星图"的视觉隐喻。

### 其他值得注意的扩展

- **StarDust**：7600 个背景星点用文明色系构成银河臂状结构（seeded random），视觉上远比随机散点有深度。
- **Filter 系统**：TopHud 扩展出文明 / 时期 / 传统 / 主题 / 关系类型五维筛选。
- **Collections**：从计划的纯 `saveNote` 扩展为 `saveItem`（收藏哲人/论证）+ `removeItem` + `saveNote`，IDB schema 版本升至 v2。

## 发现的问题

### P0 — ThoughtSystem 功能无数据支撑

`schemas.ts` 中 `thoughtSystem` 是 optional，种子脚本没有生成它。当前所有哲人的 `philosopher.thoughtSystem` 都是 `undefined`。结果：

- `StarScene.tsx` 的 `ThoughtOrbit` 每次都 `return null`
- `PhilosopherPanel.tsx` 的"思想星系"板块永远不显示

这是整个应用最有辨识度的功能，但目前对用户完全不可见。优先级高于任何新功能。

**建议**：立即写 1–2 个哲人的真实 `thoughtSystem` JSON（建议选柏拉图或孔子），端到端跑通整个流程。

---

### P1 — CameraRig 没有平滑跟随动画

```tsx
<OrbitControls target={target} enableDamping dampingFactor={0.08} ... />
```

`dampingFactor` 只作用于旋转和缩放，不作用于 `target` 位置变化。选中哲人时，轨道中心瞬间跳转，没有过渡动画。用户通过搜索定位视口外的哲人时，相机没有视觉反馈。

**建议**：用 `useFrame` + `THREE.Vector3.lerp` 手动插值 `controls.target`，或切换为 `@react-three/drei` 的 `CameraControls`（支持 `setLookAt` 动画）。

---

### P2 — 相同毫秒时间戳下的排序稳定性

`sortByUpdatedAtDescending` 依赖 `localeCompare`，快速连续操作时多个 item 可能得到相同时间戳。V8 的 `Array.sort` 从 Node 11 起是稳定的，所以测试通过，但这是隐性平台假设。

**建议**：为收藏 item 加自增序号字段，排序时 `updatedAt` 相同则按序号降序。

---

### P3 — saveMessage 状态不自动清除

`SearchPanel.tsx` 和 `PhilosopherPanel.tsx` 收藏成功后设置提示文本，但没有 `setTimeout` 清除，也没有在面板关闭/重新打开时重置。

**建议**：`setTimeout(() => setSaveMessage(""), 2500)` 写在 `setSaveMessage` 之后。

---

### P4 — `useMemo` 包装 async 函数

```tsx
const reload = useMemo(() => async () => { ... }, [repo]);
```

语义上应使用 `useCallback`。不影响功能，但会让代码审查者困惑。
