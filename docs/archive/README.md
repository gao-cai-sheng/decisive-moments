# 存档：内容生产过程记录

**这里的文件与使用、构建、贡献本项目都无关。** 想了解项目请看[根目录 README](../../README.md)；想投稿请看[开放投稿流程](../open-contribution-flow.md)。

本目录保存 542 位哲人入库过程中的过程性记录，留档是为了让每一条内容的来历可追溯 —— 哪一批、什么标准、谁审的、审出了什么问题。

## 内容

| 类别 | 说明 |
|---|---|
| `research/delivery-*.md` | 逐批交付记录：本批收了谁、依据什么来源、盲审判定与返工 |
| `research/seed-w*-candidates.md`<br>`research/seed-w*-production-spec.md` | seed 档各波次的候选名单与生产口径 |
| `research/std-u*-instruction.md` | standard 档升格批次的作业指令 |
| `research/HANDOFF-*.md`、`research/LOOP-LEDGER.md` | 阶段交接与循环作业台账 |
| `research/quality-baseline-*`、`research/review-2026-*` | 质量基线快照与外部审计回合 |
| `research/backfill-*`、`research/roster-expansion-proposal-*` | 补齐队列与扩容提案 |
| `design-drafts/` | 早期设计与规划草稿 |
| `philosophers-roster.md` / `.json` | 首版 100 人花名册（已被 542 人库取代，仅作历史留存） |
