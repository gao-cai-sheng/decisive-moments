# Plan B：种子档双轨制——哲人目录快速放大方案

时间：2026-07-04 ｜ 拟定：Claude（外部审核）＋ gao ｜ 状态：**已批准（gao 2026-07-05）**——种子档双轨制工具规则与 W1 候选名单均获批；seed 生产开闸，仍须逐批走 review-checklist §2.5 seed 门 + 盲审 PASS 后方可 admit。
目标：在不动摇现行标准档管线的前提下，把哲人目录规模从 ~250 量级快速推进到 750+ 量级，且历史证明的造假风险不随吞吐放大。

## 一、核心设计：两级档位并行

**A 轨（现行，不变）**：标准档。3 problems / 6 claims / 12 evidence、真实 works、关系网、门3 全套 + 盲审 + 外部抽检。4–6 位/批。产出"恒星+行星系"。

**B 轨（新增）**：种子档（seed tier）。每位只含**身份层数据**：
- id / names（zh+en）/ life（生卒+display）/ civilization / traditions / periods
- influenceWeight、1–2 部真实代表作（works 条目，禁占位）
- 2–3 条 relationships（连接既有哲人，维持谱系原则）
- 一段 120–200 字生平定位 summaryZh
- **禁止携带 thoughtSystem**——思想内容只允许经 A 轨管线进入，杜绝半成品思想数据混库

产出"只发光、无行星的恒星"。20–30 位/批，吞吐约为 A 轨的 6–8 倍。

## 二、为什么这个切法安全

历史上四代造假全部发生在**思想内容层**（claims/evidence/summaryZh 凑数）。种子档根本不含这一层，可造假面只剩身份事实（生卒、归属、著作名），而身份事实：
1. 可机验：每人必须在 sources.md 附 ≥1 个权威来源引用（SEP/IEP/标准工具书条目名）；
2. 可抽验：外部审核按 20% 抽比对生卒与著作归属；
3. 错误代价低：错一个生卒年是可修的元数据 bug，不是污染思想库的假内容。

## 三、数据与工具改造（codex 实施清单）

1. schema：philosopher 增加 `tier: "standard" | "seed"`（默认 standard，现库 248 位回填 standard）。
2. validate-data：seed 条目校验身份层完整性；发现 seed 携带 thoughtSystem → 硬错误。
3. quality-audit：**报数永久分档**——"标准档 N ｜ 种子档 M"，禁止合并成单一总数汇报（防口径注水）。
4. admit 管线：新增 `--tier seed` 模式，走门1/门2；门3 对 seed 只查身份层。
5. 前端（外部审核实施）：seed 恒星渲染为小而暗、无 LOD 行星、不参与名字闪烁池的加权；面板显示生平+"思想体系待深化"标记；聚焦后提供"深化优先级投票"占位（后续接升级队列）。

## 四、名单与批准流程

- 名单仍然**先报批再生产**：codex 从二期后备池 + 标准工具书目录汇编候选名单（每波 100 位，含一行理由与来源），gao 批准后进队列。
- 优先波次建议：W1 中国先秦至清代补全（约 40）；W2 欧陆/英美近现代二线（约 60）；W3 伊斯兰/犹太/印度经院纵深（约 50）；W4 20 世纪全球（约 60）；W5 女性与非主流传统专项（约 40）。

## 五、复核制度（轻量但不缺席）

- 每 seed 批仍出 review-verdict：盲审员只执行身份核查清单（随机 5 位：生卒、civilization、代表作归属、来源可查）+ 全批机验。
- 外部审核抽检：每 3 批抽 1 批；发现 1 例虚构人物 → 整批 REJECT 并暂停 B 轨（虚构人物是种子档的"模板灌水"等价物，零容忍）。
- 账本照记，工时/产出字段照填。

## 六、升级路径（后续完善）

种子档不是终点而是队列：
1. 升级即 A 轨回补——现有 backfill 机制原样复用，`tier` 从 seed 翻 standard 由 admit 自动处理；
2. 升级优先级 = 关系网中心度 ＋ 前端点击热度（后续埋点）＋ gao 手工置顶；
3. 每完成一个 A 轨批次，附带升级 0–2 位种子（挂靠相关谱系），存量自然消化。

## 七、风险与对冲

| 风险 | 对冲 |
|---|---|
| 虚构/张冠李戴人物混入 | 来源引用强制 + 20% 身份抽检 + 零容忍整批打回 |
| 汇报口径注水（把种子算成完整条目） | quality-audit 永久分档报数；对外表述规范写入 RUNBOOK |
| 星图视觉被暗星淹没 | seed 恒星降亮度/尺寸；过滤器支持"只看标准档" |
| 种子长期不升级成烂尾 | 升级配额绑定 A 轨批次（每批带 0–2 位）；台账列种子库龄 |
| B 轨挤占 A 轨产能 | B 轨限定在 A 轨停等盲审的空窗执行（泳道B 的一部分） |
