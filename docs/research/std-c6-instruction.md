## 0. 为什么这批的重点是「问题怎么写」

前端新上了「随机认识一位哲学家」：随机抽一个人，**先只亮出他真正在问的问题，不给名字**，
读者想一轮再揭晓是谁。这个钩子直接取 `thoughtSystem.problems[].questionZh`。

上线实测暴露两件事：

**（一）现有 questionZh 几乎全部以人名起句，当钩子会剧透。**

真机第一次抽到维柯，屏幕上直接显示：

```
维柯为什么认为人类最能认识自己所制造的历史世界？
```

盲盒还没揭晓，答案先说了。前端已加 `maskName()` 兜底（遮掉中英文名），但遮完变成：

```
为什么认为人类最能认识自己所制造的历史世界？
```

——通顺，但「认为」缺主语，读着悬空。**根因是这些问题是写给「已经知道是谁」的读者的**，
它们是词条内部的小标题，不是能独立站住的问题。

**（二）324/542 是种子档，压根没有问题可问。** 抽到就降级用 `keywordsZh` 最长词兜底，
屏幕上只有「语言起源」「解构存在论」这种孤零零的名词。实测连抽两次都落在这一档——
**60% 的概率，读者遇到的是最弱的形态**。

所以本批要同时做两件事：**继续升格补覆盖**（治第二件），**改问题写法**（治第一件）。

## 1. 长期口径（从本批起生效，写进每批 self-review）

### 1.1 每人至少一个「自足问题」

每位哲人的 `problems` 里，**至少一条**的 `questionZh` 必须满足全部三条：

1. **不出现人名**（他本人的、也不要用「某某学派的创始人」这类等价指认）
2. **去掉人名后主谓完整**，不留悬空的「认为」「主张」「如何看待」
3. **单独拿出来能让人想一下**——是一个真问题，不是一个词条标题

其余问题可以保持现在的写法（词条内部导航需要它们指明是谁）。**不要返工已入库的 218 位**。

### 1.2 对照：同一个问题的两种写法

| 现写法（词条标题式） | 自足写法（钩子式） |
|---|---|
| 商鞅为什么把民众的强弱、法令清楚和功赏分明视为国家强弱的关键？ | **让民众变弱，为什么反而能让国家变强？** |
| 董仲舒如何用阴阳、德刑和三纲关系把宇宙秩序转译为人伦制度？ | **如果君臣父子的等级来自天，人还能改动它吗？** |
| 慧远如何在《沙门不敬王者论》中区分在家和出家？ | **出家人该不该向皇帝下跪？** |
| 维柯为什么认为人类最能认识自己所制造的历史世界？ | **我们能真正认识的，是不是只有自己造出来的东西？** |
| 王充怎样说明《论衡》的写作目的？ | **一个说法流传得越广，是不是就越可信？** |

右列的共同点：**没有专名也成立，而且读者会不自觉地开始回答**。

### 1.3 三条红线（比口径更硬）

- **不许为了好听而改写立场。** 自足化只动问法，不动这个人实际主张什么。
  上面「让民众变弱…」仍是商鞅的原命题，不是替他缓颊，也不是替他辩护。
- **不许把问题写成心灵鸡汤。** 「我们该如何面对人生？」这类谁都能套的问句，
  比人名起句更糟——它连是谁都指认不了。判据：换一个哲人还成立，就是废话。
- **自足问题必须仍被 evidence 支撑。** 问法变了，证据链不变，`quality-audit` 照跑。
