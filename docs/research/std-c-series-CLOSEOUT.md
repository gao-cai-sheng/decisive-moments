## 1. 三类形态残留，58 条

机器门查形态，这三类它查不出来，但读者一眼能看出是坏的。

### 1.1 定位截断在半句 —— 23 条

```
《商君书·更法》：法者所以爱民也礼者所段      ← 「礼者所」+「段」，断在助词上
《商君书·错法》：用必出于其劳赏必加于段      ← 断在介词「于」
《管子·牧民》：政之所兴在顺民心政之段        ← 断在「之」
《孙子兵法·始计》：多算胜少算不胜而况于段
```

**病因**：机械截取原文前 N 字再接一个「段」。

**修法**：定位标识要是**完整可辨识的短语**，不是定长截断。取该段最能指认它的那几个字，
到语义完整处收住：

```
《商君书·更法》：法者所以爱民段
《商君书·错法》：赏加于功段
《管子·牧民》：政之所兴在顺民心段
《孙子兵法·始计》：多算胜少算不胜段
```

判据很简单：**念出来是不是一个能听懂的短语。** 断在「所」「之」「于」「而」上就是没念完。

### 1.2 繁简混用 —— 27 条

```
《毛诗笺·关雎》：先王以是經夫婦成孝敬段
《毛诗笺·樛木》：妃妾以禮義相與和合段
```

集中在 `zheng-xuan`。**本库是简体中文库**，索引、摘要、界面全是简体，
定位字段突然冒出繁体，是不一致，不是「保留古籍原貌」。

**修法**：全部转简体。原典引文若日后回补 `publicDomainExcerptZh`，那里可以保留原貌，
但 `locator` 是本库的检索字段，统一简体。

### 1.3 书名号不配对 —— 8 条

```
《高僧传》道安传》：传记记载其组织译经段      ← 多一个 》
```

全部在 `dao-an`。**修法**：`《高僧传·道安传》：组织译经段`。
篇目用间隔号连缀在书名号内，这是本库既有写法（`《论语·颜渊》`、`《商君书·更法》`）。

顺带：`《综理众经目录（佚）》：出三藏记集卷3安公经录遗迹段` 这条也重写——
既然实际引的是《出三藏记集》，就写 `《出三藏记集》卷二：新集撰出经律论录段`，
在 `summaryZh` 里说明它保存的是道安已佚的《综理众经目录》。
**引什么书就写什么书，不要把佚书名挂在实际引用的书前面。**
（卷次注意：C5 旧 verdict 已指出安录主体在卷二，不是卷三卷四。）
