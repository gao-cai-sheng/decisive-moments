## 1. 问题是什么

全库 542 位里有 92 位的 `oneLineZh` 是初始播种时自动生成的模板，一直没人回来改：

```
墨子      是伦理、政治问题谱系中的第一版候选哲人。      kw: 伦理/政治/正义
朱熹      是伦理、政治问题谱系中的第一版候选哲人。      kw: 伦理/政治/正义

龙树      是宗教、形而上学问题谱系中的第一版候选哲人。  kw: 宗教/形而上学/生死
```

两个毛病叠在一起：

1. **简介是占位符**——套一个句式，把主题名填进去，谁都能套，等于没写。
2. **关键词就是主题名**——92 人只有 13 种组合，33 个人共用「知识/自由/政治」。而 `themes` 字段本来就存着主题，关键词再抄一遍纯属浪费。

**这 92 位不是边角料**，是笛卡尔、斯宾诺莎、休谟、黑格尔、尼采、维特根斯坦、海德格尔、福柯、奥古斯丁、阿奎那、伊本·西那、朱熹、王阳明、龙树——全库最有名的一批，且全是标准档。星图上点开最多的就是他们。

**当初翻译跳过这 92 位是对的**，占位符翻成英文还是占位符。所以顺序是：先修中文，再翻英文。

## 2. 素材已经在库里了——这是本任务的关键

这 92 位**全部都有 `thoughtSystem`**，而且都过了门禁（结构、权重、反模板、溯源）。

所以你要做的是**从这个人自己的数据里提炼一句话**，不是去研究他。打开 `public/data/philosophers/<id>.json`，读：

```
thoughtSystem.problems[].titleZh              这人被归纳出的三个核心问题
thoughtSystem.problems[].questionZh           问题的具体提法
thoughtSystem.problems[].claims[].claimZh     他在每个问题上的实质立场
summaryZh                                     人级摘要
traditions / periods / themes / works         身份层信息
```

三个 problem 的标题合起来就是这个人的骨架，简介就是把这个骨架压成一句话。

> **这一条决定了本任务的风险等级**：你在做概括，不是做研究。**禁止**引入 `thoughtSystem` 里没有的说法。凡是你想写但库里没有依据的，一律不写——宁可平实，不许自由发挥。这不是保守：本项目刚刚才因为"凭印象补细节"打回过三个人。

## 4. 质量口径

### 4.1 `oneLineZh`

- **长度 25–40 字**（现有优秀条目就在这个区间）。
- **必须点出这个人区别于旁人的切口**，读完知道为什么是他而不是同学派另一个人。
- **禁止空话**：「重要哲学家」「影响深远」「奠定了基础」「作出了重要贡献」「集大成者」这类词单独出现即不合格；它们没有信息量，套谁都行。
- **禁止再出现主题名罗列**（「伦理、政治问题谱系」这种句式一个字都不许留）。

正面标杆（库里现有的，照这个水平写）：

```
36字  以苦、缘起、无我和解脱道路重塑印度思想中关于生命、执著与自由的根本问题。
34字  系统化早期斯多葛逻辑、物理学和伦理学，使斯多葛主义成为严整哲学体系。
30字  犬儒学派代表人物，用贫穷、自足和公开挑衅把哲学变成生活批判。
29字  米利都学派哲人，以气、凝聚和稀薄化解释自然变化与宇宙结构。
```

注意这四条的共同点：**都落在具体概念上**（苦/缘起/无我、逻辑/物理学/伦理学、贫穷/自足/挑衅、气/凝聚/稀薄化），没有一条靠形容词撑场面。

### 4.2 `keywordsZh`

- **3–6 个**。
- **必须是实词**：学说名、核心概念、代表作、方法。
- **禁止使用十个主题名**（`正义/伦理/知识/政治/形而上学/语言/自由/生死/宗教/美学`）作为关键词——`themes` 字段已经存了，重复没有意义。这正是本次要修掉的毛病，别再犯。
- 优先取该人 `thoughtSystem` 里反复出现的术语，和 `works` 里的代表作。

```
好： 四圣谛 / 缘起 / 无我 / 中道 / 八正道 / 涅槃
好： 我思故我在 / 方法论怀疑 / 心物二元 / 《第一哲学沉思集》
坏： 伦理 / 政治 / 正义            ← 主题名
坏： 理性主义 / 哲学 / 思想家       ← 太泛，不区分人
```

### 4.3 书名口径（本次一并定死，中英西三语后续都照此）

- **中文原著**：直接用中文书名加书名号——《传习录》《四书章句集注》。
- **非中文原著**：中文通行译名 + 书名号。若无通行译名，用**罗马化原名 + 括注意译**，例如 `Nomoi（法律篇）`。
- **不要自拟一个看起来像通行译名的东西**。拿不准就在 `notes.md` 记一笔，别硬造。

> 这条同时解决西语盲审留下的待定项：西语 keywords 里的书名此前是自拟意译，检索不到。后续西语与英语按同一原则处理——罗马化原名保底，意译放括号。
