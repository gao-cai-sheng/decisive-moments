## 3. 每批自检：两道门

### 门 1：机器门（一条命令）

```bash
node tools/text-patch-lint.mjs <patch.json> [--expect <ids.txt>]
```

查：`schemaVersion` 与 `items` 形态、id 全部存在于索引、`--expect` 给定时 id 集合恰好相等、无额外字段、`oneLineZh` 25–40 字、无占位句式残留、无空话词（重要/深远/奠定/贡献/集大成/杰出/著名）、`keywordsZh` 3–6 个且不含十个主题名、组内无重复、跨条无重复简介与重复关键词组合、`keywordsEn` 与 `keywordsZh` 等长、英文字段无中文残留、反模板（≥3 条共享 8 字首尾段）。

**必须贴真实输出到 `self-check.md`，不许只写「已通过」。**

### 门 2：人工门——机器抓不到的都在这里

首批的 6 条阻断项，**机器门全绿时一条都没抓到**。它们就是这道门的教材：

| 类型 | 实例 | 为什么机器看不见 |
|---|---|---|
| **压字数压出语病** | `以实际机缘与摄取代实体`（whitehead）——「摄取代实体」不成词<br>`把非洲人在欧权利问题哲学化`（amo）——「在欧」不成词 | 字数、字符集全合规 |
| **凭空造因果** | `并用全能限制教会绝对权力`（ockham）——源数据里「神的全能」讲的是形上必然与直观认识，「教权边界」是另一个 problem，两者无此因果 | 词都对，关系错了 |
| **术语译错** | `冷淡之物`（zeno-citium）——斯多葛 ἀδιάφορα 是「无差别之物」，「冷淡」说的是态度 | 是实词，不是主题名 |
| **把后世标签当正面切口** | `双重真理争议`（ibn-rushd）——「双重真理」是拉丁阿威罗伊派被扣的帽子，他本人主张的恰恰是宗教与哲学相协调 | 是真实术语，只是不属于他 |
| **句式别扭** | `经此在分析重提存在问题`（heidegger）——应为「以」 | 语法无误 |
| **书名口径** | `《论证》`（anselm）——Proslogion 无此通行中译 | 是个书名号 |

**逐条回答，写进 `self-check.md`**：

1. **通读一遍**。每条中文出声念一遍，卡壳的就是有问题的。压字数是本层最大的语病来源——**宁可少写一个概念，不许挤成不成词的缩写**。
2. **每个「以…并…」「用…来…」的连接**，回源数据确认这个因果／手段关系真的存在。奥卡姆那条就是把两个独立 problem 硬接成一句。
3. **每个专名术语**，确认是该人自己主张的，不是后人给他扣的标签，也不是别的学派的词。
4. **每个书名**，按 §4 口径核一遍。
5. **本批哪几条你自己没底**？写进 `open-questions.md`——主动标出不扣分，藏着被抓到才扣分。首批的 `anselm` 书名就是主动标了的，做得对。

## 4. 长期口径（跨批一致，别每批重定）

**书名**
- 中文原著：中文书名 + 书名号——《传习录》《四书章句集注》
- 非中文原著：中文通行译名 + 书名号
- 无通行译名：**罗马化原名 + 括注意译**——`Proslogion（论证）`、`Nomoi（法律篇）`
- 不许自拟一个看起来像通行译名的东西。拿不准记进 `notes.md`。

**关键词**
- 3–6 个实词：学说名、核心概念、代表作、方法
- 十个主题名（正义／伦理／知识／政治／形而上学／语言／自由／生死／宗教／美学）一个都不许用——`themes` 字段已存
- 优先取该人 `thoughtSystem` 里反复出现的术语

**简介**
- 25–40 字，点出这人区别于旁人的切口
- 落在具体概念上，不靠形容词撑场面
- 禁空话词

**英文**
- `oneLineEn` ≤120 字符；`keywordsEn` 与 `keywordsZh` 等长同序

## 5. 节奏与红线

```
选批（§2 顺序）→ 分组产出 → 门1 机器自跑 → 门2 逐条自答 → 写 self-check.md → 停车交盲审
                                        ↑ 未过就地修，别提交
```

- **分组**：每组 10–35 人，按文明或学脉分。**同一学脉连着写几十人，句式会自己收敛**——首批 33 位欧陆近代拆成六个子组是对的做法，继续照办。
- **每回合**：连续推 3–5 组再停。
- **停车必写原因**，四选一：`turn_budget`（还有剩余，人说声继续即可）／`needs_human`（撞红线或口径判不了）／`backlog_empty`（§2 清空）／`quota`。
- **打戳记**：追加到 `docs/research/LOOP-LEDGER.md`，格式照 `RUNBOOK-kimi-autonomous-loop.md` §12.2。

### 红线

1. **只写** `docs/research/tmp/<批次目录>/`。**禁碰** `public/data/` 任何文件。
2. **禁改** 四个文本字段以外的任何字段——`thoughtSystem`、`themes`、`names`、`life`、`works`、`tier` 都不许出现在补丁里（机器门会拦）。
3. **禁** 自行 admit、commit、push。产完即停，交盲审。
4. **禁** 顺手扩范围。本批名单之外的人一个不碰，看到问题记进 `notes.md`。
5. **禁** 写 `review-verdict.md`——那是盲审方的文件。
