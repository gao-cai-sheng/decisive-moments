## 2. 工作流纪律（不变）

- 生产者（codex）只写 `.research/tmp/kimi/<batch>/`，禁碰 public/data、禁 admit --write、禁 commit/push。
- 每批**新上下文盲审**，结论 PASS/REJECT 写进 `<batch>/review-verdict.md`；先看货、后看账。
- 盲审 PASS 后才 `admit --tier seed --write`；随后 `validate-data` + `quality-audit --require-standard` + `vitest` 全绿。
- seed §2.5 门：只身份层、`tier:"seed"`、禁 thoughtSystem、1–2 真实作品（禁占位 id）、2–3 关系挂靠既有哲人、sourceNotes≥1（含 URL）。

- 入库后必跑 `npm run sync:dist` 刷新星图数据。
